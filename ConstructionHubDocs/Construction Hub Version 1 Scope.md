# Construction Hub Version 1 Scope

## Version 1 Objectives

1. Reduce estimating time.
2. Improve quote accuracy.
3. Improve revision management.
4. Improve variation management.
5. Improve knowledge retention.
6. Improve reporting visibility.
7. Establish scalable architecture.

---

# Included Modules

- Company Management
- User Management
- Projects
- Builder Profiles
- Supplier Profiles
- Libraries
- AI Takeoff Engine
- Estimating
- Quote Generation
- Quote Versioning
- Revision Management
- Variation Management
- Procurement Planning
- Handover Packages
- Knowledge Base
- Reporting
- Director Dashboard

---

# Excluded Modules

Do NOT build:

- Inventory Management
- Factory Tracking
- Production Scheduling
- Installation Tracking
- Defects Management
- Payroll
- Accounting
- Tender Platforms
- CRM Systems
- HR Systems

Only build architecture placeholders where required.

→ Reporting

---

# AI Rules

AI may:

- Read drawings
- Extract dimensions
- Detect quantities
- Detect joinery types
- Compare revisions

AI may NOT:

- Create pricing
- Set margins
- Make commercial decisions

Human approval is required before changes affect quotes.

---

# Success Criteria

Version 1 is successful when:

- AI-assisted takeoffs work
- Quotes are version controlled
- Revisions are managed
- Variations are tracked
- Procurement plans can be generated
- Handover packages can be generated
- Company knowledge is retained
- Directors can view reporting
